## 2. Core Data Model & Rules
- **Dashless UUIDs:** All generated IDs must use `IdUtils.generate()` to create 32-character hex strings with no dashes (e.g., `7ed45f2bc48b419e8e4664d5ff680b0d`).
- **The "Reuse" Mandate:** You MUST reuse Root Space properties and types whenever possible to ensure cross-graph interoperability. Only create *new* properties/types for domain-specific fields.
- **Operations (Ops):** Every `Graph.*` function returns `{ id, ops }`. Operations are atomic mutations. They must be collected into an array and published together as an Edit.
- **Relations are Properties:** Relations between entities are created using `Graph.createRelation()`. The `type` parameter must be a property ID with `dataType: "RELATION"`.
